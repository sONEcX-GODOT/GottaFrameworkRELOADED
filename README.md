# 🦔 Gotta Framework RELOADED

A full-featured **Sonic Unleashed-style** framework built in **Godot 4** (GDScript) with full support for both **Android** and **PC**. Features both high-speed Daytime Sonic gameplay with iconic abilities/level objects and a basic **Werehog** (Nighttime) mode.

## ✨ Key Features
* **Cross-Platform Ready:** Smooth performance and touch/gamepad controls out of the box for Android and PC.
* **Day & Night Gameplay Styles:** High-speed Daytime Sonic physics (slopes, loops, 3D/2.5D transitions) alongside a **basic Werehog** setup inspired by *Sonic Unleashed*.
* **Core Sonic Abilities:** Includes **Boost**, **Air Boost**, **Homing Attack**, **Rail Grinding**, **Quick Step**, Drift, Slide, Stomp, and more.
* **Sonic Unleashed Level Objects:** Comes with most of the classic interactive objects from *Sonic Unleashed* (Springs, Dash Panels, Rings, Jump Boards, Rails, Enemies, etc.).
* **Advanced Effects Management:** Modular system for visual effects, trails, and shaders.
* **Beautiful Lighting:** Pre-configured dynamic lighting and post-processing setup.
* **Hedgehog Engine 1 (HE1) Importer:** Built-in support for importing `anm.hkx`, `skl.hkx`, and `model` files directly into Godot.

## 🚀 Getting Started
1. **Download the full framework:** Go to the **[Releases](https://github.com)** page and download the latest `.zip` archive (contains all scripts, scenes, models, and assets). *(The main repository branch contains the core source code).*
2. Extract the archive to a folder on your PC or Android device.
3. Open **Godot 4** (v4.x) and click **Import**.
4. Select the `project.godot` file from the extracted folder and run the project.
